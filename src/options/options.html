Capture

Turbo captures the whole page in a single pass: faster, immune to sticky headers and animation seams. It uses the debugger permission and briefly shows Chrome's "started debugging" bar during capture. The "Save as searchable PDF" and "Capture as mobile" context menu items use the same permission.

How long to wait after each scroll before shooting (stitch engine).

Countdown before every capture starts, so you can open menus or hover states first. The toolbar badge shows the remaining seconds.

Keeps scrolling to the bottom until the page stops growing, then captures. The capture still stops at the max capture height below.

Viewport width for the "Capture as mobile" context menu item, which reflows the page to a phone layout via DevTools device emulation without resizing your window.
