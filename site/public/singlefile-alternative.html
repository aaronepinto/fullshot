SingleFile and Screencappy: which one do you need?

Last verified: August 15, 2026

SingleFile saves a web page as one self contained HTML file. Screencappy saves a web page as one image. If you are choosing between them, the question is whether you want the page or a picture of the page.

Both are free, both are open source, and neither requires an account. They solve different problems and they work well side by side.

Does SingleFile produce screenshots?

No. It produces an HTML file with the CSS, images, fonts and frames inlined, so the page opens offline exactly as it looked.

It has no PNG or JPEG export and no PDF export. That is not a shortcoming, it is the design: the output is a working page, not a picture of one.

When is SingleFile the better tool?

When you want the page to still be a page. Text stays selectable and searchable, links still work, and the layout reflows.

For archiving research, saving documentation before it changes, or keeping a copy of something you will want to read and search later, SingleFile is the better answer and it is very good at it. It runs on more browsers than anything else in this comparison, including Firefox, Safari and Firefox for Android, and it has a command line tool.

When is a screenshot the better tool?

When the output needs to be an image. Bug reports, design reviews, receipts, anything you are pasting into a ticket, a document, a chat, or a slide.

An HTML file cannot be dropped into a Jira comment or a Figma board. A PNG can. That is the whole of the difference.

SingleFile requests access to all sites and Screencappy does not, but that difference is inherent to what SingleFile does: it cannot inline a page's assets without access to them. Both facts are stated here, and neither is a criticism.

Which one should you use?

Use SingleFile to keep a page. Use Screencappy to show a page.

If you do both regularly, install both. They request different things, they do not conflict, and between them they cover archiving and sharing without a subscription or an account anywhere.
